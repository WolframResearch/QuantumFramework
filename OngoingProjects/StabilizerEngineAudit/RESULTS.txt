Full stabilizer suite: 1191 tests in 13 files; 0 failures. Includes 59 new regression tests. Outside-test messages: {}.
New checks compare exact signs and tableau bits against scalar canonical evolution, cover 62-bit boundaries through 1,024 qubits, split vs single execution, symplectic invariants, V/V-dagger, malformed data, invalid wires, empty circuits, cache-key honesty, symbolic signs, measurement and state materialization.

TRADEOFFS AND LIMITS
At 128 qubits, cold encoding of 10,000 gates was about 9% slower (12.232 ms to 13.302 ms). At 1,024 qubits, the same cold workload improved 2.71x. Warm-cache results should be interpreted separately.
Reading the full "Tableau" property now materializes the expanded O(n^2) arrays on demand; the materialization row measures that deferred cost. Scalar gate/measurement paths can still convert to the existing chunk-major layout; persistence is optimized for successive bulk Clifford calls.
The first use of a circuit still performs matrix-based classification. Plan/encoding caches retain at most 16 entries each, verify the full expression on hits, and are cleared by stabilizerClearCaches[]. Warm repeated-block results do not predict speedup for unrelated one-use circuits.
An independent probe exposed a pre-existing inverse phase issue: a specific three-qubit canonical tableau fails double inversion on the unchanged source as well. Its reproduction is saved in PreExistingInverseProbe.wls and pre-existing-inverse.log. The inverse algorithm is unchanged; regression tests check that both storage forms return identical existing inverse results.
