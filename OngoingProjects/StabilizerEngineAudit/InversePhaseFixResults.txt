Stabilizer inverse-phase correction

The pre-existing inverse bug is fixed. The only production file edited for this request is QuantumFramework/Kernel/Stabilizer/GateUpdates.m. All task changes remain uncommitted and unstaged on the existing main branch. Earlier stabilizer performance improvements are retained.

CAUSE AND CORRECTION
The inverse first constructs the inverse binary symplectic matrix with zero phase, then composes it with the input. That composition already includes the input's phase. XORing the input phase into the resulting residual a second time erased Pauli signs. Even X, Y and Z incorrectly inverted to identity under the previous rule. The corrected inverse uses the residual composition phase directly. The matrix inversion, singular-tableau guard and canonical/chunk-packed/generator-packed storage choices are unchanged by this request.

The saved before/after reproduction reports the three-qubit fixture's double inverse and both composition orders as false before, true after. X, Y and Z inverse equality likewise changes from false to true. Neither reproduction emits messages. See inverse-proof-pre.json, inverse-proof-post.json and InverseRegressionProof.wls.

CORRECTNESS
Full fresh-kernel stabilizer suite: 1527 tests across 14 files, zero failures and outside messages {}. The new InversePhase.wlt contains 330 passing tests. It covers all 24 one-qubit Clifford actions; primitive adjoints; all 64 sign choices for the reported three-qubit matrix; canonical, chunk-packed and generator-packed storage; both inverse composition orders and exact double inversion; randomized reversed-adjoint circuits; independent exact dense U-dagger P U conjugation at n1-4; packed-word boundaries n31/32/61/62/63/124/125; symbolic binary substitutions; and singular-matrix messages/$Failed. The earlier CompiledEvolution inverse regression now asserts actual involution rather than agreement with the old canonical behavior.

METHOD AND LIMITS
WolframKernel 15.0.1 for Mac OS X ARM (64-bit) (July 2, 2026). Kernel startup, native-kernel compilation/warmup, input construction and expanded-tableau export are excluded from evolution times. Each measured trial clears System caches. Warm rows reuse the encoded plan; cold-encoding and cold-plan rows also empty stabilizer caches. Timed audit kernels ran sequentially, with correctness kernels finished beforehand. The 10,000-gate workload repeats one deterministic mixed-Clifford 1,000-gate block ten times. The separate randomized cold128 workload has 10,000 randomly selected mixed gates and wires, with a fixed seed. TenPublicCalls reuses the same prebuilt 1,000-gate circuit for ten successive calls. DirectOneV inserts one V into a 10,000-gate list. Matrix-based first-use public circuit classification and deferred full-tableau materialization retain the previously documented costs; neither is altered by this correction. Benchmarks measure evolution, not the inverse operation itself.
