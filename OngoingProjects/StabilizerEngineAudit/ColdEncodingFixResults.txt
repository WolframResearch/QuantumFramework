Stabilizer cold-encoding fix

The 128-qubit cold-encoding regression is removed. This turn changes only Stabilizer/Compiled.m in production, plus six stabilizer regressions. All changes remain uncommitted and unstaged on main.

IMPLEMENTATION
The encoder matches one-based wire numbers, packs the integer rows, then converts both wire columns to zero-based indices in a vector operation. It no longer evaluates each wire decrement through the interpreter. The compiled input guard uses ListQ, MatrixQ with IntegerQ, and an explicit three-column shape check. Wire ranges and two-qubit self-wire checks remain in place before the native call. Cache keys, collision checks, bounds, persistent storage and the native Clifford kernel are unchanged.
