# Continuous measurement in 2D and 3D: implementation report

Companion to the kernel-verified 1D essay `../measurement-in-a-potential.md`, whose conventions are binding throughout: hbar = mass = 1, `ft`/`ift` with `FourierParameters -> {0, -1}`, the state a normalized array with the grid measure absorbed, the measurement a Gaussian Kraus reweighting `Exp[-lambda dt (c - out)^2]` followed by renormalization, outcomes drawn as one position sample from `Abs[psi]^2` plus Gaussian noise of standard deviation `1/Sqrt[4 lambda dt]`.

Files here:

- `engine-2d3d.wl`: the 2D engine (grid, packet, channels, outcome draw, Kraus update, Strang step, runners, conditional moments, leakage checks), the multimode Gaussian filter (matrix Riccati plus record-driven means, mode-count general, per-channel detection efficiency), and the 3D core step with its own grid, moments, and channels.
- `validation.wls`: the full check battery; every line prints PASS/FAIL against a stated tolerance and the run ends with an open-failure count (currently zero).
- `benchmarks.wls`: cost profile with `ClearSystemCache[]` before every timing.

## What generalizes verbatim, and why

The 1D measurement law carries over without modification because nothing in it mentions dimension. `Fourier` on a rank-d array is already the d-dimensional transform (one 1D transform along each axis, confirmed against per-axis 1D transforms and by a manufactured plane wave landing on its own bin on deliberately non-square grids), so the essay's `ft`/`ift` pair is reused literally. The kinetic phase becomes `Exp[-I p2 dt/2]` with `p2 = Outer[Plus, px^2, py^2 (, pz^2)]` built from per-axis momentum lists stored in Fourier's rotated order, each axis exactly as the 1D grid stores it. The potential phase and every Kraus mask are pointwise on the array.

Monitoring d coordinates means d independent channels. A channel here measures the coordinate combination `u . r` at strength lambda, so axis-aligned channels and a rotated quadrature are the same code path. Simultaneously measured operators commute, so the per-channel Gaussian exponents add and one `Exp` applies all masks. The joint outcome is one position sample from the full `Abs[psi]^2` shared by every channel (the outcomes are correlated through the position), plus independent per-channel noises; sampling each channel from its own marginal would factorize the outcome law and is wrong the moment the state is not a product.

Heating is additive by the essay's own double-commutator argument, channel by channel: the drift of any quadratic Hamiltonian conserves the energy functional for arbitrary second moments, and each channel's backaction feeds it at hbar^2 lambda/2m. Both statements are verified symbolically (arbitrary symmetric stiffness matrix, arbitrary channel directions, all parameters symbolic), and the per-step momentum-variance gain of the 2D Lindblad step equals `(lambda_x + lambda_y) hbar^2 dt` to machine precision on the grid.

## What does not carry over verbatim: the traps

- **`Normalize` is 1D-only.** `Normalize[matrix]` returns unevaluated with `Normalize::nlnmt2`, and the essay's Bayes-check idiom `Normalize[arr, Total]` fails the same way (for a matrix, `Total` returns a vector, not a norm). Worse, `Norm[matrix]` is the spectral norm, so a hand-rolled `psi/Norm[psi]` would be silently wrong: on any product state the spectral and Frobenius norms coincide, so every separable test would pass, and the mis-normalization would first appear exactly when the axes entangle. The engine normalizes by `Norm[Flatten[psi]]` everywhere.
- **Orientation is a convention that must be pinned once.** Dimension 1 of the array is the x index; `Outer[Plus, xs, 0. ys]` and its momentum analogues put every per-axis list into that orientation. The joint sample inherits it for free: the grid caches the flattened list of coordinate tuples, so the weighted draw returns a position directly and no index decode exists to get wrong. What remains checkable is the marginal orientation itself (`Total[P, {2}]` versus `Total[P]`), which the leakage guards pin by parking a packet against one wall and near one momentum ladder top and demanding the alarm ring on the right axis only, and the sampler statistics on a correlated state, which would expose any transposition.
- **A channel with lambda = 0 must not exist.** Its mask would be harmless but its outcome noise `1/Sqrt[4 lambda dt]` is infinite; freezing an axis means removing the channel, not zeroing its strength inside one. The setup does that filtering, and it accepts only strengths that are numeric and provably nonnegative real (exact constants like `Pi` qualify), returning a Failure for an undetermined symbol, a negative value, or a complex value. A bare `Select` with a `> 0` test would instead drop those, quietly for a symbol or a negative number and with a `Greater::nord` message for a complex value; an undetermined strength belongs in the raw channel associations the filter's Riccati consumes, never in the grid engine. The consumers are typed on a channel list (`chans_List`), so a Failure that does escape the setup cannot flow onward as if it were an empty channel list and silently run the trajectory unmeasured; the call stays visibly unevaluated instead.
- **The weighted draw costs O(N) per step.** `RandomChoice` rebuilds its table from the flattened density every call; that is intrinsic per step (the density changes each step) and is the third cost center after the two FFTs and the masks. Batched draws with one table are valid only on a frozen state, which the sampler validation exploits.
- **State-storing runners hit memory before time.** `NestList`-style runners keep every state; harmless through 256^2, fatal for long 3D runs (a thousand 128^3 states is 32 GB, past this machine's memory). Long runs go through `momentsRun2`, which folds the state and Sows outcomes and moments only.
- **The squeezed steady width sets the resolution floor, per axis.** With about three grid points per steady width the steady variance is reproduced at the few-per-mille level; with less than one point per width it is off by tens of per mille to percents with no warning. Choosing dx after choosing lambda is part of the physics setup, and the essay's per-axis edge and momentum-tail checks remain the run-time guards.
- **Packing survives.** Every array in the step (grids, phases, masks, transforms, products) stays packed. The one place packing was at risk is grid construction from an exact-integer box length, which would seed unpacked coordinate arrays into every later step; the constructors therefore force the box lengths to machine reals themselves rather than trusting the caller.

## Costs, honestly measured

Apple M2 Pro, 32 GB, Wolfram 15.0, 2026-08-07; three unrelated kernels from a parallel session were running at full load during timing, but an uncontended re-measurement reproduced the table within about ten percent, so the load mattered little. Warm per-step comes from a short trajectory (the number a long run pays); the cold step includes first-call autoloading and transform-plan building and is a single un-repeated shot, so its column scatters between runs; components are min-of-3, each from a cold cache. The step is two rank-d FFTs, a handful of pointwise array operations, and one O(N) weighted draw, so time tracks the point count: across the 64^3 to 128^3 rows of the table the warm step grows slightly more slowly than the number of points, so the log factor is not resolved at these sizes, and at 128^2 the step is overhead-dominated.

| grid | state | warm step | cold step | ft pair | mask update | joint draw |
|---|---|---|---|---|---|---|
| 128^2 | 0.25 MB | 1.6 ms | 5.3 ms | 0.54 ms | 0.52 ms | 0.45 ms |
| 256^2 | 1.0 MB | 2.9 ms | 3.3 ms | 1.2 ms | 0.75 ms | 0.63 ms |
| 64^3 | 4.0 MB | 11 ms | 12 ms | 3.2 ms | 4.0 ms | 1.2 ms |
| 128^3 | 32 MB | 69 ms | 74 ms | 31 ms | 21 ms | 6.2 ms |

Feasible on this machine: any reasonable 2D grid (a 1500-step conditional run at 128^2 with full moment extraction takes seconds); 3D at 128^3 runs comfortably in memory with steps under a tenth of a second, so single trajectories are minutes and small ensembles are hours; 256^3 fits memory (a quarter-gigabyte state) but ensembles stop being pleasant.

The density-matrix route dies at N^2d, memory first and flops close behind:

| grid | rho memory | one dense step |
|---|---|---|
| 128^2 | 4 GB | 35 Tflop |
| 256^2 | 64 GB | 2.3 Pflop |
| 64^3 | 1 TB | 144 Pflop |
| 128^3 | 64 TB | 74 Eflop |

So unconditional physics in 2D and 3D comes from averaging seeded trajectories, and the density matrix appears only once, as a 32^2 Lindblad step used to verify heating additivity exactly. The ensemble route is validated against it: sixty seeded trajectories reproduce the additive heating slope within statistical error.

## Validation against the 1D truth

Four pillars, all in `validation.wls`, most at machine precision and the rest at the integrator's known orders. The steady state the battery compares against is not transcribed: the battery re-derives it from the Riccati symbolically, proves there is exactly one physical branch (positive, real variances for all positive parameters) and that the branch attracts (the linearized flow's eigenvalues have negative real parts), verifies purity at the fixed point, and takes its limits: switching off the trap recovers the free steady variance, the classical limit collapses the conditional variance, and infinitely strong watching pins the position exactly. The exact-flow references for the unitary checks come from `MatrixExp` of the filter's own drift matrix, so the grid dynamics and the filter's generator are tested against each other rather than against separately hand-typed formulas.

1. **Closed-form dynamics.** Free spreading reproduces the full 4x4 covariance (means, variances, symmetrized cross moments) at machine level; harmonic breathing agrees at the Strang O(dt^2) level; a single measurement update reproduces the exact Gaussian posterior at machine level, in 2D and 3D, and not only for the orthogonal-axis pair that a wrong per-marginal sampler would also pass: two simultaneous NON-orthogonal channels reproduce the added-precision posterior exactly, two channels along the same direction reduce to one at the summed strength, and the outcome cross-covariance of simultaneous channels equals the position covariance projected on both directions, which only the shared joint sample can produce. A genuinely 3D monitored run, one channel with all three components nonzero on a state correlated across the axes in a trap, stays exactly pure in the 6x6 symplectic sense while localizing the measured combination.
2. **Separable runs are two verified 1D problems.** With distinct per-axis strengths and frequencies, each axis lands on the essay's free steady width and harmonic Riccati steady variance within the same first-order splitting bias the essay itself measured, stays pure per axis, and the cross blocks stay at machine zero: the product structure survives the joint normalization and the joint sampling.
3. **Heating is additive.** Exactly, per step, in the 2D Lindblad check; statistically, in the trajectory ensemble; symbolically, for any quadratic trap and any channel set.
4. **2D contains 1D exactly.** Freeze the y axis (no y channel, flat potential, uniform ground slice) and replay the 1D essay's own record through the 2D engine: the 2D state equals the 1D state times the flat slice at every one of five hundred steps to machine precision. The conditional state is a deterministic functional of the record, which is what makes this an exact statement rather than a statistical one.

## The genuinely 2D physics

**One rotated channel in an isotropic trap.** Measuring the single combination `x Cos[theta] + y Sin[theta]` squeezes the measured quadrature's conditional variance to the essay's 1D Riccati steady value, and the grid tracks the multimode filter through the whole transient, not just at the fixed point. The orthogonal combination is a dark mode in the theorem-level sense: the pair (drift matrix, measured direction) has observability rank two of four in the isotropic trap, so the record carries no information about the orthogonal mode no matter how it is processed, and the battery asserts exactly that rank. Its conditional variance stays frozen at the ground-state value; the tiny residual ripple on the grid is the Strang splitting error on the ground state, `(hbar/2 m omega)(omega dt)^2/4`, independent of the channel angle and of the grid spacing and present with the measurement switched off entirely, and the battery pins it: the measurement-off ripple matches that closed form and quarters when the step halves. The conditional mean of the dark mode stays pinned at zero, the measurement heating flows entirely into the monitored quadrature's wandering center, and along the whole run the conditional covariance saturates the multimode uncertainty relation from both sides, every symplectic eigenvalue equal to hbar/2, the pure-state statement that has no 1D counterpart. This is the observability structure in miniature: the record controls exactly the mode it can see, and leaves the invisible mode in vacuum. The rotated steady state is verified symbolically at symbolic angle, strength, frequency, mass, and hbar, and a single-run energy gain sits beside the ensemble ramp as a realization of it (single trajectories fluctuate around the Lindblad slope; the ensemble statement is the additivity pillar above).

**A rotated anisotropic trap watched through x alone.** Tilt the trap axes so the stiffness matrix couples x and y, measure only x, and the record localizes y: the conditional y variance falls severalfold from a deliberately broad start without y ever being measured, the cross-covariance is the conduit, and the filter, fed the same record, matches the grid through the transient in the y variance, the cross-covariance, and the y mean reconstructed from the x record alone. Where the isotropic demo shows a perfectly dark mode, this one shows the opposite regime, and the battery states it at the same theorem level: through the single x channel the rotated anisotropic pair is FULLY observable, rank four of four. The demo is deliberately mid-transient; its anchor is the algebraic steady state, which solves the engine's own Riccati, is exactly pure, and is reached by the engine's Riccati flow when integrated far past the demo's length. The two regimes connect through symbolic limits the battery takes: at vanishing tilt the rotated flow collapses onto the axis-aligned one for arbitrary covariance, at degenerate mode frequencies the cross-stiffness conduit closes exactly, and the observability rank itself, taken at symbolic frequencies and tilt, collapses from four back to two in both of those limits, which is the record's reach shrinking to one mode and the reason the isotropic trap's orthogonal mode is dark in the first place. The grid's conditional covariance stays exactly pure throughout (symplectic eigenvalues pinned at hbar/2 from both sides); the filter's Euler step, started from a broad pure state, transiently dips below that floor by a bounded amount, an integrator artifact the battery measures and bounds rather than hides.

**A double well, where the filter is the wrong object.** Monitor a tilted quadrature of a quartic double well and the conditional state splits into lobes before collapsing into one: no 4x4 Gaussian can carry that, and because the measured combination mixes the bimodal x with y, the lobe structure writes itself into a large x-y cross-covariance, so the failure is genuinely two-dimensional. The filter, handed the surrogate quadratic trap with the true well-bottom curvature and fed the same record, mistracks the mean by a large fraction of its range while the grid stays perfectly healthy by its own leakage guards. This is the regime boundary of the whole Gaussian-filter picture, and the reason a grid engine is worth carrying next to it: in the quadratic demos the grid confirms the filter, and here the grid replaces it.

**A grid driven past its ceilings.** The essay closes 1D with a finite grid betraying the continuum ramp; the 2D battery reproduces that fate in trajectory form. On a deliberately small ring under strong monitoring the conditional momentum second moment cannot follow the linear heating law: whenever the packet reaches a wall or the momentum ladder top, wrap-around aliases fast components into slow ones and the seam-crossing mask re-localizes the packet, so the moment collapses episodically instead of climbing, the per-axis guards go loud mid-run, and the endpoint sits far below the ramp. The guards are therefore checked along runs, not only on final states.

**Detection efficiency.** The filter carries a per-channel efficiency: the information terms (the covariance contraction and the innovation gain) scale as eta lambda while the backaction diffusion keeps the bare lambda, and the battery verifies symbolically that the essay's rescaling (lambda to eta lambda, hbar to hbar over Sqrt[eta]) gives the eta-filter's fixed point, with the mixed-state purity hbar^2/4 eta. The grid engine itself is a pure-state unraveling and cannot carry an eta < 1 conditional state, which is mixed; its record generator likewise emits unit-efficiency outcome noise, while an eta filter is meant for a lossy detector's stream whose outcome noise is wider by 1/Sqrt[eta]. Extending the grid side means either a density-matrix propagation at small grids or an unraveling with an extra unobserved channel, the natural next step the essay's closing section points to.

## What a 2D companion essay would contain

1. **Nothing in the measurement changes.** One paragraph on why the Bayes update, the outcome law, and the record are dimension-blind, and that only the grid plumbing grows an index: the 1D essay's Part I carries over by reference.
2. **The 2D grid.** The rank-2 state, per-axis momentum lists in transform order, the kinetic quadratic form via `Outer[Plus, ...]`, the flattened-density sampler, and the two 1D-isms that break (`Normalize`, per-marginal sampling), each demonstrated in one cell.
3. **2D contains 1D.** The frozen-axis replay as the essay's first payoff cell: the same record drives both engines to the same state at machine precision. Then the separable double-1D run: two different steady widths on two axes of one wavefunction.
4. **One tilted channel.** The rotated-quadrature demo: measured mode squeezed to the 1D steady value, orthogonal mode dark and frozen in vacuum, heating carried by the monitored center. The multimode filter beside it: four means and ten covariances driven by the record against sixteen thousand amplitudes, the 2D form of the essay's five-number filter.
5. **Seeing y through x.** The rotated anisotropic trap: cross-covariances as the information conduit, the y mean reconstructed from the x record, and the filter overlay through the transient.
6. **Averaging and the price of dimension.** Additive heating from trajectory ensembles, the death of the density matrix at N^2d told through the memory table, and the per-axis edge and tail checks as the grid's honesty conditions.

## Regimes covered, and two deliberate scope decisions

The validation battery covers the five standard regimes explicitly. General symbolic: the Riccati steady state derived with every parameter symbolic, exactly one physical branch by a ForAll proof, its stability by symbolic Routh-Hurwitz over all positive parameters, the multimode fixed-point identities at symbolic strengths, frequencies, and channel angle, the same filter code certified at three modes with everything symbolic, the eta-filter fixed point, and the heating theorem for arbitrary symmetric stiffness and channel directions. Exactly solvable: the MatrixExp Gaussian flows in 2D and 3D, the exact posteriors including simultaneous non-orthogonal channels, the record-replay identity with the 1D essay for the grid, and the one-mode filter matching the essay's five-number filter component by component. Limits: trap off, classical, infinitely strong watching, vanishing channel tilt, degenerate mode frequencies. Numerical reference: grid versus filter on a shared record, the exact 32^2 Lindblad (trace, Hermiticity, and positivity of rho all asserted), the algebraic Riccati steady state, the seeded ensemble. Failure and edge: the resolution floor, the guards checked along runs and proven loud on a run past the ceilings, the rejected-strength Failure path, and the double well where the filter itself is the failing object.

Two structural choices are deliberate, not oversights. The 3D block repeats the 2D construction with its own names because the deliverable asked for a clean, readable 2D engine and the 3D core step only; the filter and its embeddings read the mode count off their arguments (certified at three modes), the moment extraction shares one Gram-matrix core across ranks, and folding the two grid engines into one rank-general engine is the natural first move of the companion essay, not of this prototype. And `hbar = mass = 1` stay global assignments because the 1D essay's conventions are binding for everything here; symbolic work rescopes them with `Block`, which is exactly what the validation's symbolic sections do.
