# Versioned copies of the backbone-method skills

These are repository-versioned copies of the two user-level skills that drive the
backbone method. The LIVE copies, the ones sessions actually load, are at:

- ~/.claude/skills/backbone/SKILL.md
- ~/.claude/skills/innovation/SKILL.md

On any difference, the user-level copies win at runtime; these copies exist so the
skills' evolution is in git history alongside the notation key and the pages they
govern. When either live skill changes, refresh the copy here in the same commit
that records why.
